# Ayman’s Library portal

First visual stage of a gradual GitHub development workflow.

The approved split layout places Library branding on the left and a translucent entry card on the right. The page includes responsive desktop and mobile layouts, a destination selector, and System, Light and Dark themes. The theme preference is saved in the current browser when storage is available.

## Preview

Open `index.html` in a current browser. No installation or build is needed.

## Current stage

The password field and Enter button are disabled, and the page explains that sign-in connection is pending. Authentication and destination access require a later integration. The source contains no Library password or authentication secrets.

## Files

- `index.html` — accessible page structure
- `styles.css` — responsive glass design and themes
- `app.js` — theme preference and system-theme handling
